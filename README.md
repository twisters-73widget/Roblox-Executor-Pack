## FAQ

### What is XCutors?

XCutors is a bundled collection of popular Roblox script executor tools for Windows, packaged together with a universal loader for convenience.

### Which executors are included?

The package includes Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal launcher.

### What operating systems are supported?

XCutors is designed exclusively for Windows 10 and Windows 11 desktop environments.

### How do I update the executors?

The universal loader checks for updates automatically. You can also manually download the latest release from the GitHub Releases page.

### Can I add my own scripts?

Yes. You can place custom .lua script files in the designated scripts folder or paste script content directly into the executor's editor.

### Is XCutors free to use?

Yes, XCutors and the included loader are free. Individual executors may have their own licensing or access requirements.

### Why does my anticomponent flag the application?

Some anticomponent engines may flag script executors due to their injection behavior. You can add an exclusion for the XCutors folder, but always download from this official repository.

### How do I switch between executors?

Open the xcutorsLoader and select a different executor from the dropdown menu before attaching to Roblox.

### Where can I find scripts to run?

Many community scripts are shared on forums and script hubs. The built-in script browser in some executors also provides categorized scripts.

### I'm getting an error on launch. What should I do?

Ensure you are running the application as Administrator, that your anticomponent exclusion is set, and that Roblox is open before attaching. Check the logs folder for detailed error information.
